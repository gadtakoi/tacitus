# Tacitus

Сервис приёма, записи и раздачи RTSP-видеопотоков: принимает потоки через MediaMTX, хранит записи, отдаёт файлы из
S3/MinIO и защищает всё это JWT-аутентификацией.

## Язык

### Потоки

**Поток** (stream):
Именованная точка, в которую публикуется видео и из которой его читают. В API MediaMTX то же самое называется **path**;
наружу Tacitus отдаёт только слово «поток», а `path` встречается лишь в адресах Control API (`/v3/paths/list`).
_Избегать_: path, канал, камера

**Конфигурация потока** (stream configuration):
Хранимое в Tacitus описание потока — имя, источник, признак записи. Существует независимо от того, публикует ли кто-то
сейчас видео. _Избегать_: настройки камеры, stream settings

**Активный поток** (active stream):
Поток, о котором MediaMTX прямо сейчас сообщает своё состояние: готов ли он, кто публикует, сколько читателей. Это
**не** то же самое, что конфигурация:
сконфигурированный поток может быть неактивен, а активный — не иметь записи в конфигурации. _Избегать_: живой поток,
running stream

**Источник** (source):
Откуда берётся видео: `publisher` — его присылает внешний клиент, либо URL вида `rtsp://…`, по которому MediaMTX
забирает поток сам. _Избегать_: вход, input, upstream

**Публикатор** (publisher):
Тот, кто отправляет видео в поток: камера, ffmpeg, любой RTSP-клиент. Также имя учётной записи MediaMTX с правом
`publish`. _Избегать_: источник (в значении «клиент»), издатель, стример

**Читатель** (reader):
Тот, кто получает видео из потока. Также имя учётной записи MediaMTX с правами
`read` и `playback`. _Избегать_: зритель, потребитель, subscriber

### Записи

**Запись** (recording):
Видео, сохранённое MediaMTX на диск в виде fmp4-сегментов. Живёт локально ограниченное время. _Избегать_: файл, дамп,
capture

**Сегмент** (segment):
Один файл записи. Сегменты нарезаются по времени, а не по границам событий. _Избегать_: чанк, часть, фрагмент

**Архив** (archive):
Запись, выгруженная в S3/MinIO и удалённая с локального диска. Переход «запись → архив» необратим: локальной копии после
него не остаётся. _Избегать_: бэкап, холодное хранилище

### Аутентификация

**Access-токен** (access token):
Короткоживущий JWT, которым клиент подтверждает право на каждый запрос. _Избегать_: токен (без уточнения), bearer,
сессия

**Refresh-токен** (refresh token):
Долгоживущий JWT, обмениваемый на новую пару токенов. Одноразовый: при обмене отзывается и заменяется новым. _Избегать_:
токен обновления, долгий токен

**Ротация** (rotation):
Обмен refresh-токена на новую пару. Старый токен при этом всегда отзывается — ротация без отзыва не считается ротацией.
_Избегать_: обновление токена, продление

**Семейство токенов** (token family):
Все refresh-токены одного пользователя, связанные цепочкой ротаций. Отзывается целиком при подозрении на кражу.
_Избегать_: сессии пользователя, цепочка токенов

**Обнаружение повторного использования** (reuse detection):
Признание refresh-токена скомпрометированным, если он предъявлен после того, как уже был потрачен. Следствие — отзыв
всего семейства. _Избегать_: replay-защита, детект дубликатов

**Отзыв** (revocation):
Досрочное аннулирование токена до истечения его срока. Для access-токена означает попадание его `jti` в чёрный список,
для refresh-токена — отметку времени отзыва. _Избегать_: инвалидация, блокировка токена

**jti**:
Уникальный идентификатор конкретного JWT. Именно он, а не сам токен, хранится при отзыве access-токенов. _Избегать_: id
токена, token id

**Блокировка перебора** (brute-force lock):
Временный отказ в аутентификации после серии неудачных попыток. Порогов два:
на пару «имя пользователя + IP» и на имя пользователя со всех адресов сразу. _Избегать_: бан, лимит попыток

### Аудит

**Security-событие** (security event):
Запись о значимом для безопасности действии: вход, отзыв токена, выдача файла, обнаружение повторного использования.
Пишется в отдельный журнал. _Избегать_: лог, аудит-запись, событие (без уточнения)

**Подозрительная активность** (suspicious activity):
Всплеск ответов 401/403 с одного адреса за короткое окно. Единственный вид события, который сохраняется в базу, а не
только в журнал. _Избегать_: атака, аномалия, инцидент

### Файлы

**Presigned URL**:
Временная подписанная ссылка на объект в S3/MinIO. Сама по себе является разрешением на скачивание: предъявлять учётные
данные по ней не нужно. _Избегать_: прямая ссылка, временная ссылка
